Política de Privacidade – Nova TV

Última atualização: 23 de novembro de 2026.

O Nova TV é uma tela inicial pessoal para uma única TV, usada apenas pelo próprio dono. Não é vendido, não exibe anúncios e não tem servidor próprio.

Quais dados são acessados

Se o dono da TV conectar a conta do YouTube, o Nova TV pede acesso somente leitura (permissão youtube.readonly) para listar os vídeos que a conta curtiu e os vídeos recentes dos canais em que ela é inscrita. Nada é publicado, alterado ou apagado na conta.

Como os dados são usados

Os títulos, nomes de canais e miniaturas são usados só para mostrar esses vídeos na tela inicial da própria TV.

Onde os dados ficam

Tudo fica guardado apenas na memória interna da TV (cache que se renova a cada poucas horas). Nenhum dado é enviado para servidores do Nova TV ou de terceiros, além das próprias APIs do Google/YouTube e do TMDB usadas para buscar as informações.

Compartilhamento

Os dados não são vendidos, compartilhados nem usados para publicidade.

Como remover o acesso

Na própria TV: Nova TV → Perfil → Desconectar YouTube (apaga o acesso e o cache). Ou a qualquer momento em myaccount.google.com/permissions.

O uso das informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.
